# 授業管理アプリ

## はじめに
日本語の個別授業を受講する学習者と、授業を管理する運営者向けの 授業予約・ユーザー管理Webアプリケーション です。

友人が個人経営している日本語塾があり、授業管理のために毎回SNSでチャットをしているため、本来の日本語授業という業務とは関係のない部分で時間的・精神的コストがかかっていました。
授業管理アプリを作成し運用することで友人の余暇時間やストレスの改善が見込まれるのではないかと思い、授業管理アプリの作成を提案しました。
作成の承諾をいただき、現在作成中です。
このアプリの運用が始まると学生ごと・授業ごとの調整のためのチャット時間や、スケジュール管理の改善が見込まれます。

学習者はアカウントを登録して授業を予約・確認・変更・キャンセルできます。管理者はユーザー情報や授業の受付可能時間を管理できます。主に海外の日本語学習者による利用を想定し、日本語・中国語の表示に対応しています。

## 概要
個別授業の予約受付と管理をWeb上で完結させることを目的に開発しました。

最も基本的な機能は以下の2つです。
- 学習者が空き時間を確認しながら予約できる仕組み
- 管理者が授業の受付枠を設定できる仕組み

いずれの場合もDBへ登録する時には受付時間や既存予約との重複を検証し、同時操作による二重予約を防ぐための制御を設けています。

また、Spring Securityによる認証・認可、MyBatisによるデータアクセス、JUnit・Mockitoによるテストなど、バックエンド開発に必要な設計・実装にも取り組んでいます。

## 主な機能

### 学習者・管理者向け
| 機能 | 	内容 |
| --- | --- |
|アカウント登録  |　電話番号・パスワード・学習目標などを登録   |  
| ログイン・ログアウト  |	Spring Securityによる認証。パスワードはハッシュ化して保存 |
| ユーザー情報の確認・編集（未実装） | ログイン中の本人の情報を表示・更新 |
| 授業予約 | カレンダーで受付可能な日時を確認し、予約候補を選択して登録 |
| 予約一覧 | 登録済みの授業予約を確認 |
| 予約変更・キャンセル | 所定の期限内で予約を変更・キャンセル |
| 多言語表示 | ブラウザ設定言語に合わせて日本語・中国語の画面表示を切り替え |

### 管理者向け
| 機能 | 	内容 |
| --- | --- |
| ユーザー管理 | 	登録ユーザーの一覧・詳細を確認 |
| 授業受付枠の管理 | 月単位のタイムライン画面で受付可能時間を確認・追加・変更・削除 |
| 受付枠の一括反映 | 編集内容をクライアント側で一時保持し、検証後にまとめて登録 |


予約処理の特徴
- 予約可否の検証：受付枠の範囲、既存予約との重複、受付可能時間の連続性を確認
- 同時予約への対策：予約登録処理で排他制御を行い、同一枠への競合を防止
- サーバー側での再検証：画面表示後に予約状況が変化した場合も、登録時にチェック
- カレンダーのデータ取得：REST APIから対象月の受付枠・予約状況を取得
- 権限ごとのアクセス制御：一般ユーザーと管理者で利用可能な機能を分離

## データベース
開発・テストではH2 Database、本番環境ではAmazon RDS for MySQL8を使用しています。
アプリケーションからのデータ操作にはMyBatisを利用しています。
|テーブル|役割|
| --- | --- |
| `users` | 学習者・管理者のアカウント情報 |
| `goal_levels` | 学習目標レベルのマスタ |
| `reservations` | 授業予約の日時・状態 |
| `lesson_openings` | 管理者が設定する授業の受付枠 |
| `reservation_settings` | 受付枠の開始・終了時刻の設定 |
| `reservation_lock` | 授業・受付枠の登録時に排他制御をおこなうためのテーブル |
